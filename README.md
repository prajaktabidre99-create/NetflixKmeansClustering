# 🎬 Netflix Movie Recommendation System Using K-Means Clustering & Hybrid Collaborative Filtering

## 📌 Project Overview

This project focuses on building a **Netflix Movie Recommendation System using K-Means Clustering and Hybrid Collaborative Filtering**.

The system analyzes movie ratings and user preferences to generate relevant movie recommendations.

K-Means Clustering is used to group similar data points, while Hybrid Collaborative Filtering combines recommendation approaches to improve movie suggestions.

## 🎯 Objectives

- Build a Netflix movie recommendation system.
- Analyze user ratings and movie preferences.
- Apply K-Means Clustering.
- Implement Collaborative Filtering.
- Develop a Hybrid Recommendation approach.
- Generate relevant movie recommendations.
- Explore Machine Learning techniques for recommendation systems.

## 🧠 Algorithms Used

### 1. K-Means Clustering

K-Means is an unsupervised Machine Learning algorithm that groups similar data points into clusters.

In this project, clustering can help identify groups with similar movie-rating or preference patterns.

### 2. Collaborative Filtering

Collaborative Filtering recommends movies based on user interactions, ratings, and similarities between users or movies.

### 3. Hybrid Recommendation System

A Hybrid Recommendation System combines multiple recommendation techniques to generate movie suggestions.

It aims to use the strengths of different recommendation approaches.
